2. Multi-Code RAG Metadata Boost (dtcMatch: true)
Storing all 5 companion codes in dtcCodes[] guarantees Stage-1/Stage-2 retrieval awards the exact-DTC boost whether the technician scans P0300, P0302, or P0016.

Model Context Protocol (MCP) Architecture & Live Hardware/Fleet Integration

Rather than coupling diagnostic tools inside a monolithic application server, the system implements Anthropic & Google's Model Context Protocol (MCP). Gemini 3.8 Flash acts as an MCP Host connecting over JSON-RPC 2.0 (stdio and SSE) to four independent tool servers.

  • fetch_freeze_frame: Extracts millisecond freeze frame snapshot when DTC P0300 tripped under 18.4 PSI boost at -4°C.

The 4 Concrete Guardrails to Add to Our Codebase

Guardrail Layer What It Protects Against How We Implement It in server.ts & app/agent.py
1. Input Compliance & Tamper Guardrail Prompt injection ("Ignore instructions...") or illegal shop tampering ("How do I bypass the airbag occupant sensor or delete the DPF/catalytic converter?"). Pre-check regex + policy classifier in POST /api/chat and POST /api/guardrails/test (runInputComplianceAndPiiGuardrail) that immediately returns a compliance refusal (BLOCKED_BY_SAFETY_POLICY) without spending LLM tokens.
2. PII / Repair Order Scrubber Technicians pasting raw customer Repair Orders containing names, phone numbers, or credit card numbers into chat. Pre-LLM regex/DLP sanitizer that masks [REDACTED_PHONE], [REDACTED_EMAIL], and [REDACTED_CARD] while keeping the 17-character VIN and DTC codes intact.
3. MCP Physical Actuation Interlock Gemini accidentally calling run_actuator_test while the engine is running or without technician approval. Policy check inside POST /api/mcp/invoke and executeMcpToolCall() that blocks bidirectional commands unless interlockConfirmed !== false, gear === "PARK", and engineRpm === 0.
4. Deterministic Torque & HV Safety Enforcer Gemini hallucinating a bolt torque spec (e.g., 25 Nm instead of 15 Nm) or forgetting a lethal 400V High-Voltage warning. Extends existing verify_diagnostic_contradictions in app/agent.py and retrieval/torque_filter.py via runOutputTorqueAndSafetyGuardrail() in server.ts to compare every numeric torque value in the LLM text against the retrieved manual's torqueSpecs JSON and overwrite/flag any mismatch.
